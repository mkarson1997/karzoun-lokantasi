# Contributing

Contributions are welcome, especially around accessibility, responsive behavior, form validation, reusable components, documentation, and the roadmap toward a real backend.

Before opening a pull request:

1. Keep the customer journey intact across menu, account, order and profile pages.
2. Test affected pages locally on desktop and mobile widths.
3. Avoid introducing fake authentication, payment, or persistence claims.
4. Include screenshots for visible UI changes when useful.
5. Keep commits focused and explain the reason for the change.

For larger architecture changes, open an issue first.
