# Security Policy

This repository is currently a front-end portfolio project. It should not be treated as production authentication, ordering, or payment software until a hardened backend and server-side controls are added.

If you discover a security issue affecting the deployed site, repository integrity, dependencies, forms, or future users, please report it privately through the maintainer's GitHub profile before publishing exploit details.

A useful report includes reproduction steps, affected files, impact, and a suggested mitigation when available.

Never commit credentials, API keys, customer data, payment information, or production secrets to this repository.
